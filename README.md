# Python Exercises 🐍

A comprehensive collection of Python practice notebooks created using Google Colab. This repository covers fundamental concepts, data structures, and progressive coding challenges to strengthen Python programming skills.

## 📁 Repository Structure

### Data Structure Practice
* **`list_practice_probs.ipynb`** – Exercises focusing on list manipulation, methods, indexing, and slicing.
* **`dict_practice_probs.ipynb`** – Practice problems using dictionaries, key-value pairs, and dictionary methods.
* **`set_practice_probs.ipynb`** – Exercises working with mathematical sets and set operations.
* **`tuple_practice_probs.ipynb`** – Problems dedicated to immutable tuple sequences.

### General Practice Notebooks
* **`Practice_probs.ipynb` to `Practice_probs8.ipynb`** *(incl. `Practice_probs6ipynb.ipynb`)* – Foundational practice sets covering basic syntax, control flow, functions, and logic.
* **`practice_probs5.ipynb` & `practice_probs9.ipynb`** – Additional foundational problem sets.
* **`practice_probs10.ipynb` to `practice_probs16.ipynb`** – Advanced problem sets moving into more complex algorithms and problem-solving.

## 🚀 How to Use

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/Aarya-Musale/python_exercises.git](https://github.com/Aarya-Musale/python_exercises.git)

```

2. **Open in Google Colab:**
You can upload any of the `.ipynb` files directly to [Google Colab](https://colab.research.google.com/) to run and edit the code interactively.

## 💡 Requirements

* Python 3.x
* Jupyter Notebook or Google Colab environment
